# RunHutch

**Network Booster for Android**

RunHutch keeps your mobile data connection active and responsive. Turn it on with a single tap and let it work quietly in the background while you browse, stream, or use your apps.

**[Download RunHutch v0.8 (APK)](https://github.com/SunethUdayanga/RunHatch-Moblie/releases/download/0.8/RunHatch.0.8.apk)**

> Android only. You may need to allow installation from unknown sources in your device settings before installing the APK.

---

## Features

- **One-tap boost** — Start or stop the network booster from the main screen.
- **Runs in the background** — Keeps working even when you switch to other apps or lock your phone.
- **Live status** — See when the service is active and how many requests have been sent.
- **Customizable settings** — Set your target URL and how often requests are sent.
- **Persistent notification** — A small notification shows that the booster is running so you always know it is on.

---

## How to Use

1. Install the app from the download link above.
2. Open RunHutch and tap **Network Booster** to start.
3. Tap again to stop when you are done.
4. Tap **Configure** (top right) to change the request URL or countdown interval.

---

## Permissions

RunHutch may ask for permission to run in the background and show notifications. These are needed so the network booster can keep working while you use other apps.
